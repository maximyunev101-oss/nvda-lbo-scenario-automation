# Public-Company Take-Private LBO Automation Tool (NASDAQ: NVDA)

An advanced investment banking and private equity scenario tool that automates dynamic 3-statement forecasts, 5-year debt waterfall structures, and Sponsor IRR/MOIC sensitivity matrices.

## Key Features
- **Integrated Financial Engine:** Automates data ingestion for multi-statement financial statement linkages.
- **Debt Waterfall Schedule:** Models multi-tranche debt sizing (Senior Secured & Subordinated) with a voluntary/mandatory levered free cash flow cash sweep.
- **Algorithmic Sensitivity Matrix:** Programs multi-variable sensitivity testing running varying Entry EBITDA Multiples against Leverage levels to track targeted Sponsor returns.
- **Stress-Testing Engine:** Simulates a custom Downside Case featuring a 15% revenue haircut and 300 bps EBITDA margin compression to evaluate underwriting margins of safety.

## Built With
- Python 3.x
- pandas (Data manipulation & financial scheduling)
- numpy (Financial math execution & array structures)
